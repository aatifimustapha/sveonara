Steg-För-Steg: Så Installerar Du IPTV

Gör dig redo att kapa kabeln! Vår enkla installationsguide leder dig genom hur du ställer in Swedish Nara på din TV, mobil eller dator på bara ett par minuter.

Välj din enhet nedan:

Följ dessa enkla steg för att titta direkt på din Smart TV utan externa boxar:

  1. Gå till app-butiken på din TV (Samsung Smart Hub eller LG Content Store).
  2. Sök efter någon av följande appar: IBO Player (rekommenderas!), IPTV Smarters Pro eller Flix IPTV.
  3. Installera och öppna appen på din TV.
  4. Appen visar en Device ID och Device Key (eller MAC-adress) på skärmen.
  5. Skicka dessa uppgifter till vår WhatsApp-support, eller fyll i dina Xtream Codes (Server URL, Användarnamn, Lösenord) direkt i appens inställningar.
  6. Starta om appen och alla dina 22 000+ kanaler och TV-guide (EPG) är redo att användas!
  1. Öppna App Store på din Apple TV eller iPhone/iPad.
  2. Sök efter och installera Smarters Player Lite, TiviMax eller IPTVX.
  3. Välj alternativet "Log in with Xtream Codes API".
  4. Fyll i dina inloggningsuppgifter:
    Namn: Swedish Nara
    Användarnamn: (Ditt användarnamn från WhatsApp)
    Lösenord: (Ditt lösenord från WhatsApp)
    Server URL: (Server-URL från ditt välkomstmeddelande)
  5. Klicka på "Add User" så synkroniseras kanalerna automatiskt i 4K HDR!
  1. Sök efter och installera appen Downloader i Amazon Appstore.
  2. Gå till Firestick-inställningar -> My Fire TV -> Developer Options -> aktivera "Install unknown apps" för Downloader.
  3. Öppna Downloader och skriv in koden: 6468112 och klicka på Go.
  4. Installera TiviMate IPTV Player eller IPTV Smarters Pro.
  5. Öppna appen och logga in med dina Xtream-koder.
  1. Öppna Google Play Butik på din TV eller box.
  2. Sök efter TiviMate IPTV Player och klicka på Installera.
  3. Starta TiviMate -> Välj "Lägg till spellista" -> Välj "Xtream Codes".
  4. Fyll i dina inloggningsuppgifter från välkomstmeddelandet.
  5. Tryck på Nästa och vänta i 30 sekunder medan kanallistan och EPG laddas in.

Du kan välja mellan tre enkla sätt:

  • Smarters Pro för Windows/Mac: Ladda ner installationsfilen från vår App-sida och logga in med dina Xtream-uppgifter.
  • Web Player: Titta direkt i Google Chrome eller Safari via webbläsarlänken.
  • VLC Media Player: Öppna VLC -> Medier -> Öppna nätverksström -> Klistra in din M3U-länk.
  1. Gå till inställningar på din box -> Servrar / Portaler.
  2. Ange Portal URL som vi skickat till dig på WhatsApp.
  3. Skicka din boxens MAC-adress (börjar vanligtvis på 00:1A:79:...) till vår WhatsApp-support för registrering i servern.
  4. Starta om boxen – klart!
