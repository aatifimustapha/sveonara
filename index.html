Så Här Ställer Du In IPTV På Din Enhet

Klicka på din enhet nedan för att se en snabb och enkel installationsguide.

  1. Öppna App Store på din Apple TV, iPhone eller iPad.
  2. Ladda ner Smarters Player Lite, TiviMax IPTV eller IPTVX.
  3. Öppna appen och välj "Log in with Xtream Codes API".
  4. Ange Server-URL, Användarnamn och Lösenord som vi skickat till dig på WhatsApp.
  5. Klicka på "Add User" så synkroniseras alla 22 000+ kanaler och VOD-filmer i 4K HDR!
  1. Öppna app-butiken Samsung Smart Hub på din TV.
  2. Sök efter och installera någon av följande appar: IBO Player (starkt rekommenderad!), IPTV Smarters Pro eller Flix IPTV.
  3. Öppna appen och notera din MAC-adress eller Device ID / Device Key som visas på skärmen.
  4. Skicka uppgifterna till vår WhatsApp-support, eller fyll i dina Xtream Codes direkt i appen.
  5. Starta om appen och alla dina livekanaler och full EPG är redo att användas!
  1. Öppna LG Content Store på din LG Smart TV.
  2. Sök efter IBO Player, IPTV Smarters Pro eller Flix IPTV och tryck på Installera.
  3. Starta appen och notera Device ID & Device Key på skärmen.
  4. Mata in dina inloggningsuppgifter (Xtream API koder) eller skicka koden till vår WhatsApp-support för omedelbar registrering.
  5. Starta om appen och njut av stabil 4K-streaming utan extern box!
  1. Installera appen Downloader från Amazon Appstore.
  2. Gå till Inställningar -> My Fire TV -> Developer Options -> aktivera "Install unknown apps" för Downloader.
  3. Öppna Downloader och skriv in nedladdningskoden: 6468112.
  4. Installera APK-filen för TiviMate IPTV Player eller IPTV Smarters.
  5. Öppna appen, logga in med dina Xtream-uppgifter och njut av marknadens snabbaste zappning!
  1. Öppna Google Play Butik på din Android TV, Xiaomi Mi Box eller Nvidia Shield.
  2. Sök efter och installera TiviMate IPTV Player (marknadens ledande app).
  3. Klicka på "Lägg till spellista" -> välj "Xtream Codes".
  4. Fyll i serveradress, användarnamn och lösenord som du fått via WhatsApp.
  5. Klart! TiviMate synkroniserar direkt svensk TV-guide (EPG) och 4K-sändningar.

För datorer har du tre enkla och smidiga alternativ:

  • Sveonara Web Player: Titta direkt i Google Chrome eller Safari via din webbläsare utan att installera program.
  • IPTV Smarters Pro för Windows/Mac: Ladda ner installationsprogrammet från vår App-sida och logga in med Xtream Codes.
  • VLC Media Player: Öppna VLC -> Medier -> Öppna nätverksström -> klistra in din personliga M3U-länk.
  1. Gå till inställningar på din MAG eller Formuler (MyTVOnline).

  5. Starta om boxen och alla kanaler och TV-serier är laddade!
